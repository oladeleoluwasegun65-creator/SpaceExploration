# 🌌 Space Website Landing Page

A sleek, modern, and interactive two-section landing page built to demonstrate advanced CSS animations, responsive layouts, and interactive UI components such as a custom "Terms and Conditions Apply" modal/button toggle.

Created for practical learning and frontend skill demonstration.

---

## 🚀 Features

* **Two-Section Layout:** Designed with a clean split structure showcasing immersive space-themed aesthetics.
* **Pure CSS Animations:** Smooth keyframe animations and transitions built entirely without heavy JavaScript frameworks.
* **Interactive UI Elements:** Features functional interactive buttons, including a dedicated state toggle for terms and conditions.
* **Fully Responsive:** Adapts seamlessly across different screen sizes and devices.

---

##  Built With

* **HTML5** — Semantic markup and structure
* **CSS3** — Custom styling, Flexbox, Grid, and keyframe animations
